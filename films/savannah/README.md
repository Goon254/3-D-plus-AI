# Savannah film — production folder

The 5-minute ensemble short from `CHALLENGE-SAVANNAH.md`. Read the files in order:

1. `01_premise_and_beats.md`: logline, cast (want → need, gift, flaw), theme, three-act beat sheet
2. `02_screenplay_draft1.md`: first full draft (5:50)
3. `03_story_critique.md`: story editor's notes: structure, hero agency, setups and payoffs, kid check, producibility
4. `04_screenplay.md`: **production draft**: per-scene intent, music cue, gaits, shot list (≈ 5:20 before trims)

Species research for the cast lives in `src/animatica/knowledge/species/`.
