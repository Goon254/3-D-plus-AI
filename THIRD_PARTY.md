# Third-party software, models and assets

No third-party source code is vendored in this repository (`third_party/` is empty). The following are
used as **external dependencies** — installed separately and called as libraries or subprocesses.

| Name | URL | License | What we use it for | How |
|---|---|---|---|---|
| Blender (`bpy` 5.3) | https://www.blender.org | GPL-3.0-or-later | modeling, animation, rendering, .blend files | pip wheel, inside the GPL adapter process |
| ffmpeg | https://ffmpeg.org | LGPL-2.1+/GPL | encode MP4 (H.264 + AAC), contact sheets | external program |
| Rhubarb Lip Sync 1.14.0 | https://github.com/DanielSWolf/rhubarb-lip-sync | MIT | audio → mouth shapes | external program (setup script) |
| Kokoro-82M | https://huggingface.co/hexgrad/Kokoro-82M | Apache-2.0 (weights) | default text-to-speech | ONNX model via kokoro-onnx in the TTS worker |
| kokoro-onnx | https://github.com/thewh1teagle/kokoro-onnx | MIT | Kokoro runtime | pip, TTS worker only |
| espeak-ng (via kokoro-onnx / phonemizer) | https://github.com/espeak-ng/espeak-ng | GPL-3.0-or-later | grapheme→phoneme fallback | inside the TTS worker only |
| Piper (`piper-tts`) | https://github.com/OHF-Voice/piper1-gpl | GPL-3.0-or-later | fallback TTS | subprocess from the TTS worker |
| Piper voice en-us-kathleen-low | https://github.com/rhasspy/dataset-voice-kathleen | dataset CC0 | fallback voice | downloaded by setup script |
| Piper voice en-us-libritts-high | http://www.openslr.org/60/ | dataset CC BY 4.0 — *LibriTTS by Zen et al., Google; derived from LibriSpeech/LibriVox* | fallback voice | downloaded by setup script |
| numpy | https://numpy.org | BSD-3-Clause | audio synthesis, mixing | pip |
| pydantic | https://docs.pydantic.dev | MIT | protocol models & validation | pip |
| Pillow | https://python-pillow.org | HPND | image utilities | pip |

## Generated content

All meshes, materials, animation, music and ambience in the example films are **generated by
Animatica's own code** (procedural recipes and numpy synthesis) — no external assets. Voices are stock
Kokoro voices (no cloning). Showcase renders are therefore covered by this repository's license.
